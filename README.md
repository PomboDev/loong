# Loong's Curse

This project is mainly inspired by the platformers mario 64 and mario odyssey. The main goal was a vertical slice of an tutorial level.

When we planned the project at the beginning I was going to be the main 3d artist, but I ended up making all the code and all the 3d part as well.

I think the biggest win with this project was the architecture I developed to implement features. We have the features/ folder which contains some generalized modular code and within core/ we have our "glue" where we implement most of the features and scenes.
